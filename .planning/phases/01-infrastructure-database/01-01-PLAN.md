# Plan 01-01: Add Qdrant to Docker Compose & Environment Config

## Objective

Add Qdrant as a service in both `docker-compose.yml` (prod) and `docker-compose.dev.yml` (dev), expose ports 6333 (REST/dashboard) and 6334 (gRPC), add volume persistence, configure healthcheck, and wire `app` service to depend on Qdrant being healthy. Add `QDRANT_HOST` and `QDRANT_PORT` env vars to `.env.example`.

## Context

<read_first>
- `docker-compose.yml` — existing structure to replicate for Qdrant
- `docker-compose.dev.yml` — dev variant, needs same Qdrant addition
- `.env.example` — current env vars to extend
- `.planning/phases/01-infrastructure-database/01-RESEARCH.md` — Qdrant healthcheck command and port details
</read_first>

## Tasks

### Task 1: Add `stockmind_qdrant` service to `docker-compose.yml`

<action>
Add the following service block to `docker-compose.yml` under the `services:` key (after `stockmind_db`):

```yaml
  stockmind_qdrant:
    image: qdrant/qdrant:latest
    restart: unless-stopped
    ports:
      - "6333:6333"
      - "6334:6334"
    volumes:
      - stockmind_qdrant_volume:/qdrant/storage
    healthcheck:
      test: ["CMD-SHELL", "curl -sf http://localhost:6333/readyz || exit 1"]
      interval: 10s
      timeout: 5s
      retries: 5
      start_period: 20s
    networks:
      - stockmind
```

Then add `stockmind_qdrant_volume:` under the `volumes:` key.

Then update the `app` service `depends_on:` to also include:
```yaml
      stockmind_qdrant:
        condition: service_healthy
```

Add env vars to `app` service `environment:` block:
```yaml
      QDRANT_HOST: stockmind_qdrant
      QDRANT_PORT: "6334"
```
</action>

<acceptance_criteria>
- `docker-compose.yml` contains `stockmind_qdrant:` service with `image: qdrant/qdrant:latest`
- `docker-compose.yml` contains `6333:6333` and `6334:6334` port mappings
- `docker-compose.yml` contains `stockmind_qdrant_volume:/qdrant/storage` volume mount
- `docker-compose.yml` contains healthcheck with `curl -sf http://localhost:6333/readyz`
- `docker-compose.yml` `app.depends_on` contains `stockmind_qdrant: condition: service_healthy`
- `docker-compose.yml` `app.environment` contains `QDRANT_HOST: stockmind_qdrant`
- `volumes:` section contains `stockmind_qdrant_volume:`
</acceptance_criteria>

### Task 2: Add `stockmind_qdrant` service to `docker-compose.dev.yml`

Add the same env vars to dev `app.environment`:
