## Tasks

### Task 1: Create `0002_add_documents.sql` migration

<action>
Create file `schema/migrations/0002_add_documents.sql` with exact content:

```sql
-- +goose Up

CREATE TABLE IF NOT EXISTS documents (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name        VARCHAR(500) NOT NULL,
    file_type   VARCHAR(10) NOT NULL CHECK (file_type IN ('pdf', 'docx', 'md', 'txt')),
    size_bytes  BIGINT NOT NULL,
    status      VARCHAR(20) NOT NULL DEFAULT 'pending'
                    CHECK (status IN ('pending', 'processing', 'ready', 'failed')),
    chunk_count INT4 NOT NULL DEFAULT 0,
    strategy    VARCHAR(20) NOT NULL DEFAULT 'recursive'
                    CHECK (strategy IN ('recursive', 'fixed', 'paragraph', 'semantic')),
    error_msg   TEXT,
    created_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at  TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TRIGGER set_documents_updated_at
    BEFORE UPDATE ON documents
    FOR EACH ROW EXECUTE PROCEDURE trigger_set_timestamp();

-- +goose Down

DROP TRIGGER IF EXISTS set_documents_updated_at ON documents;
DROP TABLE IF EXISTS documents;
```
</action>

<acceptance_criteria>
- `schema/migrations/0002_add_documents.sql` exists
- File contains `-- +goose Up` and `-- +goose Down` markers
- File contains `CREATE TABLE IF NOT EXISTS documents`

- File contains `CHECK (file_type IN ('pdf', 'docx', 'md', 'txt'))`
- File contains `CHECK (status IN ('pending', 'processing', 'ready', 'failed'))`
- File contains `CREATE TRIGGER set_documents_updated_at`
</acceptance_criteria>

### Task 2: Create `schema/queries/documents.sql` sqlc queries

<action>
Create file `schema/queries/documents.sql` with exact content:

```sql
-- name: CreateDocument :one
INSERT INTO documents (id, name, file_type, size_bytes, strategy)
VALUES ($1, $2, $3, $4, $5)
RETURNING *;

-- name: GetDocumentByID :one
SELECT * FROM documents WHERE id = $1;

-- name: ListDocuments :many
SELECT * FROM documents ORDER BY created_at DESC;

-- name: UpdateDocumentStatus :exec
UPDATE documents
SET status = $2, chunk_count = $3, error_msg = $4
WHERE id = $1;

-- name: DeleteDocument :exec
DELETE FROM documents WHERE id = $1;
```
</action>
