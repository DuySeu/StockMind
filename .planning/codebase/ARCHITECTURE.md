# ARCHITECTURE

## Layered Architecture
StockMind employs a standard Client-Server architecture with a clean separation of concerns on the backend.

### **1. Presentation Layer (Frontend)**
- Built with React + Vite.
- Implements a modern SPA architecture.
- Communicates with backend via REST and WebSockets (for live streaming / MCP updates).

### **2. API Routing & Middleware (Backend)**
- `github.com/go-chi/chi/v5` routes incoming HTTP requests.
- Custom middlewares for CORS, Auth, logging.
- WebSocket handler attached for bi-directional real-time events. 

### **3. Application & Business Logic Layers**
- **Service Layer**: Handles core operations and logic abstraction (`/internal/service`).
- **Agent Layer**: Manages the AI Assistant lifecycle (`/internal/agent`). Orchestrates interactions with LLMs using Anthropic/OpenAI, and invokes external Tools.
- **MCP Engine**: (`/internal/mcp`) manages tool calling through the Model Context Protocol, allowing the AI to query databases, web-search via Tavily, and more.

### **4. Data Access Layer**
- Code-generated by `sqlc`. Database interfaces interact tightly via pure Go code mapping to `pgx` structures (`/internal/database`), preventing manual mapping errors.

### **5. Data Storage**
- PostgreSQL 17 serving the primary relational data model, with `goose` maintaining schema versioning and migrations.
